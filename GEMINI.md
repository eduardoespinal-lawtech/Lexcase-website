# Reglas del Proyecto Lexbell-Website

- **Límite de espacio de trabajo**: Este proyecto corresponde exclusivamente al sitio web (`Lexbell-Website`).
- **Regla estricta de la aplicación**: Siempre que el usuario mencione o pida algo relacionado con la aplicación (`Lexbell_Aplicacion` o la app de escritorio), debes advertirle de inmediato:
  > *"Estás en el proyecto de la web, no me modifiques la app, esto es para la web."*
  Bajo ninguna circunstancia se debe modificar código de la aplicación de escritorio (`Lexbell_Aplicacion`) desde este espacio de trabajo.
- Mantén el código limpio, sin dependencias ni archivos huérfanos.
- Siempre explica y pide confirmación antes de aplicar modificaciones que impacten la estructura o contenido del sitio.
